# Ummer K. Aboobacker | Industrial Portfolio

An accessible, responsive, static professional portfolio for piping, mechanical supervision and industrial construction experience.

## View locally

Open `index.html` in a modern browser, or serve the repository with:

```sh
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Privacy

The public CV is a short, purpose-built extract. Original CV supporting documents, identity records, membership cards and training scans are intentionally excluded.

## Deployment

GitHub Pages can publish directly from the `main` branch root. No build command or dependencies are required.


The uploaded `portfolio-update.zip` is unpacked into the site by the GitHub Actions workflow in `.github/workflows/deploy-portfolio-update.yml`.
